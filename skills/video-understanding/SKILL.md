# 内置视频理解

此技能描述应用已经实现的处理流程，不向纯文字模型赋予视觉能力。

调用入口为工作台的“视频分析”或项目 API `/api/projects/{project_id}/actions`，`kind=analysis`、`analysis_kind=video`，用户选择素材、输入目标并确认费用。服务器选择支持的具体模型并冻结 `video_route`；外部提供的路由不能覆盖服务器选择。

实际执行由 `creative_agent.video_understanding.VideoUnderstanding` 负责：

1. 验证项目范围和媒体就绪状态。
2. 原生视频型号发送原片；图像型号按镜头、前3秒及全片位置抽取至多36张实际帧，并保留实际PTS和图片顺序。
3. 读取已有时间戳字幕或本地ASR结果，保留来源和人工核对状态。无文字稿时明确标记语音缺口。
4. 将真实画面及时间信息交给已配置且兼容的模型；生成带来源、观察间隔和限制的分析记录。
5. 后续对话沿用范围和已有证据；不自动调用视频生成、不扩大来源或付款方。

抽样不等于逐帧观察，不能保证捕捉快速动作、短暂字幕和音乐/语气；应回到原片核对。原生视频接口同样不能凭接口名称推定音轨支持。纯文字模型只能处理文字或其他视觉模型提供的观察结果。

不得凭本地协议测试宣传真实账户、模型质量、全渠道或成本验收通过。所需模型由用户自行配置和付费；不附带凭证或模型权重。
