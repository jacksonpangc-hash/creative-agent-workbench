# Creative Agent

适用 0.5.0：创建分析、我的笔记与历史；解析、脚本比较和报表作为当前对话的工具。所有业务逻辑共用项目 worker，不能用提示词代替应用能力。新建视频/图片生成与仿拍任务已取消，旧数据保留。

1. 使用已启动的本地桌面工作空间。CLI 可用时先检查 `creative-agent --help`；桌面包自带 worker 与本地口播识别，不要求用户安装 Python、配置转写环境变量或首次下载模型。
2. 项目清单：`creative-agent project list`；建立项目：`creative-agent project create --name 名称 --budget 金额`。经授权用 `creative-agent ingest --project ID --file 绝对路径 --source own` 导入文件；只复制到本地，不调用付费模型。
3. 使用应用启动的会话及 `CREATIVE_SESSION_TOKEN`，通过 `creative-agent api /api/projects/ID/state` 读取状态。令牌只用于本机鉴权，不写进项目或报告。
4. 分析与解析使用 `/actions`，字段和场景分支见[共享接口参考](references/api.md)。保留 directed/exploration/inspiration 三模式和 video/spoken 两种分析方式；先确认模型、素材/行业引用范围和费用预留。无素材讨论须明确选择。笔记由用户明确保存，重复保存保持幂等；可复用要求存为我的指令。
5. 蝉妈妈 CMM 是唯一可新建任务的行业数据来源。先检查权益、来源保留/模型处理授权和本次积分上限；未知费率或响应 schema 未就绪时停止，不用收费请求试探格式，不让用户填写响应映射。真实账号未验证时如实保留缺口。
6. 不扩大项目、来源、账户或素材范围。引用使用系统返回的素材/参考 ID 与实际时间点；本地转写、上游文案/分镜/画面理解须区分来源，不能把抽样帧说成逐帧理解，也不能用空素材冒充行业证据。
7. 新生成提交与旧生成重放不可用。已提交且有供应商编号的历史任务只查询原任务；结果不确定时不重发，实际成本未知保持待核账。既有授权不扩展到新计费批次。
8. 广告创建、发布或预算变更仍需单独确认。凭证只存系统密钥库；导出不带凭证，不输出密钥或读取用户其他密钥。
