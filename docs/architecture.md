# 本地创作架构（0.5.4）

Tauri/React 连接本机 FastAPI。SQLite 保存商品、素材身份、观察、脚本版本、许可和费用；媒体仍在本机。FastEmbed、FTS5、QdrantLocal 为可重建的派生索引，不建立共享行业库。

资料变更经 SQLite outbox 和持久 index_job 增量处理，单 worker 持有 Qdrant 客户端。返回结果和发模型前重读主库校验版本、用途和项目；撤销或过期资料不能靠旧向量放行。索引失败时保留关键词路径，不上传到付费 embedding。

CreativeContextService 为首轮、换方向、本地查找和局部修改提供分池召回与快照。局部改稿复用本稿资料，换方向重新检索。生成仍经既有 BYOK、用途、脚本和预算约束。

浏览器 MV3 扩展通过 Rust Native Messaging host 访问作用域受限的本机收藏 RPC。host 使用系统密钥库的独立桥密钥，不持有桌面 root bearer；网页内容不能授予项目或模型权限。

默认本地部署。当前内部产物和设备状态以该版本交付记录为准，架构存在不等于所有渠道和商用验收通过。

2026-10-25 增量：本地服务在数据库、媒体和索引初始化前取得操作系统持有的工作空间写入锁；启动失败和有序退出时释放。项目内的 `task_draft` 保存对话和脚本编辑缓存，使用版本与操作 ID，冲突生成恢复副本。它与人工确认的脚本版本分开，恢复项目时仍可继续编辑。任务预览只读且不调用模型；本地素材状态查询不建立收费任务。
