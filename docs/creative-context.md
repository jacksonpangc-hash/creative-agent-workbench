# 创作上下文与检索

商品事实按当前商品/规格直接读取，参考表达、自有镜头、人工确认偏好分别检索。参考参数不能进入本品事实。默认当前项目；明确选材继续约束范围，独立自有素材范围可以覆盖默认选择但不能跨项目。

关键词采用 SQLite FTS5、中文二元词及英文词，向量使用固定中文 BGE 512 维离线模型。两路排名以 RRF(k=60) 融合，不把分数解释为爆款概率。每池候选最多40；最终最多6参考、12自有片段、3历史偏好，并有文本长度及来源多样性限制。

每轮保存 context_snapshot_id、版本、支持项、入选/排除理由。资料未知、台词有疑点、仅有链接、错商品、错规格、过期或撤销时不作为正向创作依据。没有参考可写基于商品资料的创意草稿，但不声称采用了爆款规律。

发送模型前调用 revalidate_context。旧稿不补写不存在的帧ID；当前已失效依据须刷新。脚本保存、人工版本、原片回看及五格式导出继续使用现有对象。

只采样的视觉观察只能证明实际提交帧中的内容；自动台词用于结构参考不等于逐字校对或商品事实。模型自然语言是否准确仍需回看与人工判断。

项目备份保留历史 context 与引用关系。恢复为新项目时仅冲突的记录 ID 重映射，来源和版本保留，原项目不覆盖。恢复快照标为 archived_restored，可回看和人工改稿，但不能直接重放给模型；需要基于当前授权资料重新检索。模型凭证、浏览器授信和派生向量不恢复。
