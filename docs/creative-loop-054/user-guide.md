# 0.5.4 内部候选版使用说明

本版支持本地素材整理、视频拆解和拍摄脚本创作。云端分析由你连接的模型服务计费；蝉妈妈属于可选付费来源。本版还未通过正式商用验收，浏览器商店版待上架。

1. **打开应用**：解压当前设备对应的应用，保留原版本和原资料。建议先运行同目录“启动隔离体验.command”，使用独立的 CreativeAgent-Preview054 资料目录体验，不自动导入原库。原库完整迁移尚未验收；正常使用原资料前先保留备份并退出旧版。本次交付只构建了 macOS Intel 包。
2. **连接模型**：在“设置 → 模型服务”填写自己的服务与 Key，选择项目默认服务。日常创作继承设置，不必每次选择厂商。正常任务成功后才显示最近成功记录。
3. **添加商品和素材**：选定商品／规格，补充可确认的卖点及来源。将可用于制作的自有素材与只供研究的参考分别归类。资料会在本机整理；不需要配置向量服务。
4. **开始创作**：在“写脚本”说明受众、场景、时长和拍摄限制。默认查找当前项目已有资料；主动选材后就按所选范围研究。没有可靠台词或画面时，结果会保留缺口。
5. **回看与改稿**：展开“查看创作依据”，可看商品依据和已有片段。点引用回看原片；编辑台词或画面后“保存新版本”。“全部创作 → 脚本”可以重新打开。导出对应已保存版本。
6. **保存网页参考**：正式 Chrome／Edge 商店入口仍待上架，当前提供内部开发扩展及安装材料。安装并登记本机桥后，扩展首次连接需要在桌面“设置 → 参考来源”允许目标项目。以后可连续保存，随时撤销。收藏链接不等于已经取得视频；当前给定抖音链接的元数据收藏已用户辅助通过；快手和媒体获取仍未验收。作者主页不会作为待补视频。
7. **备份和恢复**：在“设置 → 本地资料”下载含原片的项目备份，恢复时创建新项目。模型 Key、浏览器授信和软件许可不随项目迁移，需重新配置。历史创作依据可回看；再次用于 AI 创作前须按当前资料重新核验。

若任务状态为“待核账”，先核对供应商账单；不要反复点击重做。模型人民币／美元费用与蝉妈妈积分分别统计。不明收费不会自动释放，也不会自动充值。

到期或停用不会删除本地资料；第三方受限内容的查看与迁出仍受原使用条件约束。正式签名、公证、商店发行、其他系统设备与授权服务部署尚未验证。
