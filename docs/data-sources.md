# 参考来源与收费边界

免费路径：自有文件、主动收藏、链接/表格导入及受控 yt-dlp 取片。收藏成功与媒体取得、台词可用、画面观察分别记录；无法取片保留原链接并提示补文件。不读 Cookie，不自动转付费。抖音、快手的实际支持分别记录。

付费路径为客户自接蝉妈妈。保存 Key 不启用自动搜索；项目允许外部补充、确实缺参考且现有权益/用途/费率/积分满足时，才建立 DataRequestPlan。普通改稿不新增查询。默认最多2检索请求、3条内容请求；异步轮询不能藏进免费操作。未知响应、费率或余额不触发请求。

新 API 请求资格与已取得内容使用权分别校验。API 检查超过24小时，不自动撤销本来允许保留的资料；内容过期、被撤销或合同要求持续订阅时仍会阻止使用。缓存不是永久授权。

模型货币、数据积分、token使用和供应商账单分开。日常模型分析不要求填写单价或金额；金额限制为高级可选设置，缺单价显示费用未知，自愿设置的零额度仍阻止收费。任务的素材范围、调用次数、取消、幂等和未知提交保护继续生效，不把应用控制承诺为供应商绝对账单上限。已发出且扣费不明的请求保留占用；核账要求账单编号与依据，不为恢复使用清空历史。蝉妈妈积分及具体操作费率独立核实，不因模型费用设置改变而自动授权。
