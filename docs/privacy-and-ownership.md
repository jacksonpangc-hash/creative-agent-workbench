# 本地资料、凭证与资料保全

素材、商品资料、脚本与索引留在客户资料目录。本地 embedding 不发送原文；BYOK 生成只发送本次必要且允许模型处理的材料。模型和数据 Key 存系统密钥库，原文、请求 Authorization、整段 base64 和 Cookie 不进入普通日志。

浏览器只主动读取当前页。首次桌面确认后限定安装实例、扩展来源和允许项目，持续授权可撤销。连接密钥由本机桥读取，扩展不持有 root bearer 或模型 Key。已保存参考与浏览器授信分开，撤销连接不伪造删除历史。

“导出创作记录”不含视频；“备份项目”含获准导出的真实媒体、校验清单及版本。恢复到新项目，不能覆盖旧项目或复活浏览器授权；模型凭证重新绑定。派生索引不作为主数据备份，恢复后可重建。第三方受限内容仍按原许可检查。

公开源码与本机运行资料分开。发行归档排除真实素材、台词、数据商响应、密钥、Cookie、签名私钥、账单、私人截图和个人路径。未经明确授权不推送公开仓库或发布 Release；Git 历史需单独审查，干净源码快照不等于旧历史适合公开。
