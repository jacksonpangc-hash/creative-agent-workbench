## Binary release gate

The 0.5.1 candidate excludes the wheel's nonfree FFmpeg executable. It supplies the inspected FFmpeg 7.1 + x264 executable as a separate process, reporting GPL-2.0-or-later with nonfree disabled. Exact hashes, configure flags and the source archive identity are recorded in `docs/followup-050/distribution-inventory.json`; corresponding sources, the portable build script and license texts accompany the worker and the delivery. The executable is stored in an archive to prevent the bundler from rewriting its inspected bytes, then checked before private extraction and execution. `imageio-ffmpeg` remains only the launcher library. Its wrapper license does not relicense FFmpeg. Source-project publication does not grant rights to vendor media, data feeds, API accounts or trademarks.

No public binary release or legal clearance is claimed. The CI artifacts are unsigned development builds; source compliance, Windows/macOS install verification, signing and notarization remain release gates. Runtime data is user supplied. No proprietary competitor code, prompts or paid data are distributed.

The 0.5.0 desktop build embeds whisper.cpp and the multilingual small model (SHA256 `1be3a9b2063867b937e64e2ec7483364a79917e157fa98c5d94b5c1fffea987b`). Their MIT texts, exact build manifest and source references are included with the worker. Weight downloads occur only during development packaging; the application does not download models at runtime. Legacy optional faster-whisper dependencies retain separate transitive license obligations when installed. Team deployment images (PostgreSQL, Caddy and Keycloak where configured) have their own upstream licenses and image/source obligations, separate from the Python inventory.

## Embedded export font in 0.5.0

`src/creative_agent/fonts/CreativeSansSC-Regular.ttf` is a static weight 400 instance derived from Google Fonts Noto Sans SC and renamed Creative Sans SC. It is distributed under SIL Open Font License 1.1; original copyright and the full OFL are included in `fonts/OFL.txt`. Download and derived-file SHA-256 values and the exact transformation are recorded in `fonts/provenance.json`. The font is embedded as subsets in PDF exports, so a reader does not need a separate Chinese language pack. The font license is independent of application licensing. No proprietary operating-system font is redistributed.
