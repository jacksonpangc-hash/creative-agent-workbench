# Chrome / Edge 商店提交资料

名称：创意工作台 · 保存参考

简介：主动保存当前抖音、快手网页选中的公开参考到本机项目，不读取 Cookie 或其他标签页。

详细介绍：

在平台网页发现值得研究的表达，点击收藏工具读取当前页，勾选要保存的参考，选择项目并保存。首次连接在创意工作台桌面应用明确确认一次，之后可持续收藏。新增、已有和待补视频状态可通过保存回执查看。

收藏公开链接与取得合法视频分别处理。页面缺失指标保留为空；互动量不代表销量。创意工作台默认本地运行，收藏内容不上传至开发方服务器。需要先安装配套桌面应用。

单一用途：用户主动将当前网页公开参考保存到本机创意工作台。

审核演示步骤：安装已签名配套桌面应用 → 新建本地项目 → 扩展连接 → 桌面确认项目 → 打开公开平台页面 → 读取当前页 → 选择/保存 → 查看真实回执 → 重开弹窗再保存 → 桌面撤销后确认保存被拒绝。

图标：包内 icons/icon-16.png、icon-32.png、icon-48.png、icon-128.png，沿用桌面品牌。

发布前待填：实际发行主体及联系渠道、公开隐私政策 URL、Chrome 商店 ID / URL、独立 Edge 商店 ID / URL、审核截图和签名安装包下载地址。不得填写虚构账号、下载入口、用户数、销售效果或已通过审核的表述。

发行版本从 manifest.json 获取，不能将旧源码版本号冒充本轮安装包版本。
