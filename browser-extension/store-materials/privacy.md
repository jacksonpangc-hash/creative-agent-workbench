# 创意工作台 · 保存参考隐私说明

本工具帮助你主动收藏当前抖音、快手网页中的公开参考，到你选择且桌面明确允许的本机项目。

仅在你点击“读取当前页面”时，读取当前标签页可见标题、作者、链接和页面可见互动原文。不会读取 Cookie、账号登录凭证、密码、私信、其他标签页或完整浏览历史。不会自动下载视频，也不会把互动指标推断为销量。

选择保存的内容通过浏览器官方 Native Messaging 发往你电脑上的创意工作台。扩展没有开发方远程服务器，不向开发方上传收藏内容。模型或数据服务调用由桌面应用另行设置和授权，收藏扩展不持有其密钥。

扩展本地保存随机安装标识、连接标识、已选项目、请求编号及最近公开保存回执，以便关闭弹窗后继续使用。连接密钥仅保存在系统密钥库。桌面应用保存授权项目、授权时间、到期和撤销状态、来源与收藏记录。

你可以在桌面“设置 → 参考来源”撤销浏览器连接，在桌面管理已保存资料，或卸载扩展清除其浏览器本地存储。撤销连接不会自动删除已保存参考。桌面项目资料的保留与删除由你管理。

公开发布前，发行方须在商店资料填写真实主体、联系渠道和本政策公开地址；这些尚未配置的外部字段不得用虚构信息替代。
